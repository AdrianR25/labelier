# 🏷️ Image Label

A simple, modern web app for quickly labeling images in your local folders, perfect for dataset creation.

---

## 🚀 Features

- **No Uploads:** Works directly with your local files—your images never leave your device.
- **Fast Navigation:** Use keyboard shortcuts or buttons to move through images.
- **Easy Labeling:** Assign, update, and export labels with a click.
- **Progress Tracking:** See your progress as you label.
- **Persistent Workspace:** Resume where you left off, even after closing the browser.

---

## 🛠️ Tech Stack

- **Vanilla JavaScript (ES6+)**
- **IndexedDB** for local storage
- [**Bootstrap**](https://getbootstrap.com/) for quick and easy styling

---

## 📦 Getting Started

1. **Clone this repo:**
   ```bash
   git clone https://github.com/AdrianR25/labelier.git
   ```
2. **Open `app.html` in your browser.**
3. **Start labeling!**

> **Note:** For full functionality, use a Chromium-based browser (like Chrome or Edge) that supports the File System Access API.

---

## 📄 Export Format

Labels are exported as a text file:

```text
cat1.jpg<tab>cat<lf>
dog2.jpg<tab>dog<lf>
```
